Um site responsivo desenvolvido como projeto de estudo para simular o lançamento do Grand Theft Auto V, utilizando apenas HTML, CSS e JavaScript.

📋 Descrição do Projeto
Este projeto foi desenvolvido com fins educacionais para praticar e demonstrar habilidades em desenvolvimento web front-end. O site simula uma página de lançamento do jogo GTA V, incluindo seções informativas, galeria de mídia e design responsivo.

✨ Funcionalidades
✅ Design responsivo para mobile e desktop

✅ Navegação por seções suave (smooth scrolling)

✅ Galeria de imagens do jogo

✅ Layout moderno com efeitos visuais

✅ Animações e transições CSS

✅ Formulário de contato simulado

✅ Botões interativos com efeitos hover

🛠️ Tecnologias Utilizadas
HTML5 - Estrutura semântica do site

CSS3 - Estilização e animações

JavaScript - Interatividade e funcionalidades

Font Awesome - Ícones

Google Fonts - Tipografia
