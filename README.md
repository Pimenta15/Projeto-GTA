# Site de Lançamento do GTA V - Projeto de Estudo
Projeto de um site responsivo desenvolvido para praticar HTML, CSS e JavaScript, simulando uma página de lançamento do jogo GTA V.

## 📋 Sobre o Projeto
Site estático criado como exercício de aprendizado das tecnologias front-end, com design inspirado no jogo Grand Theft Auto V.

## 🚀 Funcionalidades
Design responsivo
- Navegação suave entre seções
- Animações e efeitos visuais
- Formulário de contato simulado

## 🛠️ Tecnologias Usadas
- HTML5
- CSS3
- JavaScript
